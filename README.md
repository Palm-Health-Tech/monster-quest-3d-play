# Monster Quest 3D

A low-poly 2.5D browser rebuild of **Monster Quest** — same world, same canon, same rules as the original 2D RPG, now a 3D diorama. Nineteen maps, 216 species, turn battles, party/box/codex, gyms, a rival, four legendary encounters, and two endings.

Play it here: https://palm-health-tech.github.io/monster-quest-3d-play/

The page is one static file with no tracking and no network need (fonts degrade offline). Your progress is saved in your own browser.

Development happens inside the [Monster Quest repository](https://github.com/Palm-Health-Tech/monster-quest) under `web/monster-quest-3d/`; this page mirrors that build. Source changes land there (with a 39-test browser suite gating them) and get synced here.
